# 酒馆 APP 布局 · st-app-layout

SillyTavern 第三方扩展：把酒馆界面改造成手机 App 操作习惯（底部 Tab + 二级页面 + 返回手势），**完全保留酒馆原有功能与第三方插件**。

当前版本：**v0.9.0（TauriTavern 兼容测试版）** —— 在 v0.8.7 基础上做 TauriTavern 兼容化：openChat 等保存队列清空（`isChatSaving` live binding）+ 校验角色真的切换 + 校验聊天真的加载 + 失败重试；新聊天顶栏补 meta（解决无头像无卡名）；`minimum_client_version` 降至 1.13.0（TauriTavern 上游 1.18 可装）。**仅 TauriTavern 测试用**，本机酒馆仍用 v0.8.7。

> 本版专门用于在 TauriTavern 里安装测试。装上后重点验证：从聊天列表点历史聊天是否还报「Invalid character chat target」、顶栏是否有头像/角色名。把结果（成功/仍报错+具体报错）反馈，用于决定是否合并回主线。

---

## 安装 / 启用

1. 本目录已位于酒馆第三方扩展目录：
   `D:\data\SillyTavern\public\scripts\extensions\third-party\st-app-layout\`
2. 浏览器打开酒馆（默认 http://127.0.0.1:11451 ），进入 **扩展(Extensions) → 第三方扩展**，找到「酒馆 APP 布局」，**开启它**。
3. 刷新页面（若还是旧版，Ctrl+F5 强刷），底部出现 4 个 Tab 即加载成功。

## 使用

- 底部 4 个 Tab：**聊天 / 角色 / API / 设置**。默认停在聊天。
- 聊天 Tab：最近聊天记录列表（头像 / 角色名 / 最后消息预览 / 时间），点条目进入聊天界面；每条右侧 `⋮`：置顶 / 复制分支 / 删除。
- 角色 Tab：角色卡片网格（手机竖屏 2 列，可搜索）+ 点卡片弹出**角色概括**（大头像/标签/描述/对话数/开场白数/Token 数）+ **开始聊天**（开场白按卡片实际条数选择，空卡只有「自由开始」）+ **编辑**（进原生角色编辑）+ 右下 `+` 导入（文件 / 链接）。
- API Tab：App 风格列表，点击打开对应原生设置面板（连接与模型 / 预设与采样 / 高级格式 / 世界书 / 扩展）。
- 设置 Tab：UI 主题（二级页：皮肤 / 圆角 / 密度 / 主题色 / 布局模式 / 原生主题块）/ 酒馆原生设置全量入口 / 扩展插件逐条入口 / 数据与维护 / 布局 / 诊断与版本。
- 聊天界面：顶部 `←` 返回 + 圆形头像 + 角色名 + `⋯`（角色管理 / 世界书 / 预设采样 / 正则 / 人设 / 生图 / TTS / Token 统计 / 插件 / 开始新聊天 / 关闭聊天）。
  - 消息流与输入框是**酒馆原生 `#chat` / `#send_form`**，swipe / 编辑 / 删除 / 生成 / 状态栏 / 心动回复等插件照常工作。
  - 所有原生二级界面（世界书 / API / 扩展 / 插件面板）统一搬入覆盖层，自带 `← 返回 + 标题`，返回键逐级回退。
- 设置 Tab：**APP 布局开关（保命绳）** / 刷新列表 / 重新加载 / 诊断信息 / 版本。

## 保命绳（重要）

| 状况 | 怎么退回原版 |
|---|---|
| 正常情况 | 设置 Tab → 关闭「APP 布局」开关 |
| 插件出错 | 自动退回（错误条会提示，不静默失败） |
| 界面崩了点不到开关 | 地址栏加 `?st_app_layout=off` 刷新（或手机端重开页面） |
| 彻底移除 | 扩展管理里关闭它；或删除本目录，刷新 |

**不修改任何酒馆数据**：不动聊天记录 / 角色卡 / 配置文件，全是 DOM 层布局改造。

## 窄屏说明（v0.1~v0.3 翻车的根因，已双保险处理）

酒馆 `style.css`（1.19.0 第 6092 行）在 `≤1000px` 时把任意 `.draggable` 强制为
`width:100vw; height:100vh; z-index:9999`。本插件：

1. 自建层级全部 **> 9999**（内容 10010 / 顶栏 10015 / Tab 10020 / 遮罩 10030 / 弹层 10040 …）；
2. 在 APP 模式下显式压制这条 `@media` 规则（`body.st-app-on .draggable`，CSS 第 11 节）。

## 主题兼容

- 只做布局、不做配色：所有颜色继承 `--SmartTheme*` 变量，**无写死色值**（错误条例外）。
- 换任意第三方纯配色主题 → 新元素自动跟随。
- 检测到 claude-surface 等**改布局**的扩展会提示二选一。

## 隔离验证

`_dev/narrow-test.html`：脱离酒馆的窄屏验证宿主（375×812 … 1600×900 一键切换）。
`_dev/narrow-sim.html`：模拟酒馆 DOM + 主题变量 + 真实 `style.css`，实时打印计算样式与断言
（可用 Edge 无头模式自动量测：`msedge --headless=new --dump-dom "file:///…/narrow-sim.html#chat=1"`）。

## 主题系统（v0.6.0）

**兼容酒馆原生主题系统**：所有颜色 token 默认映射 `--SmartTheme*` 变量，换任何第三方纯配色主题，本插件 UI 自动跟随（无需任何 JS）。切主题时强调色也会实时重算。原生主题选择仍走设置→UI 主题里的「酒馆原生主题」块。

**内建 4 套皮肤**（设置 → UI 主题 → 皮肤）：
- **流光玻璃**（默认）：半透明 + 毛玻璃 + 发丝线 + 柔和阴影，最华丽。
- **纸感**：不透明 + 细边框，均衡且高性能。
- **极简**：无模糊无阴影，极速（最高性能，老设备推荐）。
- **夜光**：强调色浸润表面 + 激活辉光，科技感。

**可调**：圆角（利落/圆润/大圆角）、密度（舒适/紧凑）、毛玻璃开关（一键降性能负担）、主题色 6 选（含「跟随主题」；默认对中性灰主题自动回退暖橙，提升开箱观感）。

**性能预算**：`backdrop-filter` 全插件最多 4 处（页面/顶栏/Tab栏/弹层），且仅玻璃/夜光皮肤启用；纸感/极简/`st-app-flat`/酒馆 `no-blur` 全局关闭模糊；列表项与卡片零模糊零重阴影；长列表用 `content-visibility: auto` 跳过屏外渲染。

**解耦原则不变**：皮肤只覆盖本插件新建导航层的结构性 token，绝不碰 `.mes` 气泡等原生元素配色。

可视化预览：`_dev/theme-sim.html`（浏览器直接打开，可点选皮肤/圆角/密度/弹层/聊天视图实时预览）。
